# ecommerce-sales-analysis


# Анализ продаж интернет-магазина электроники

## Бизнес-цель
Проанализировать транзакционные данные за 6 месяцев для выявления ключевых драйверов выручки, определения VIP-клиентов и оценки динамики среднего чека.

## Инструменты
Python, Pandas

## Что было сделано
1. **Интеграция данных:** Объединены 3 разрозненные таблицы (заказы, клиенты, товары) с помощью `pd.merge`.
2. **Feature Engineering:** Рассчитана целевая метрика `revenue` (выручка) на уровне каждой строки заказа.
3. **Сегментация:** Выявлены топ-5 клиентов, генерирующих максимальный доход.
4. **Временной анализ:** Рассчитана динамика среднего чека и количества заказов по месяцам с использованием `pd.to_period`.
5. **Многомерный анализ:** Построена сводная таблица (`pivot_table`) для оценки популярности категорий товаров в разрезе городов.

## Ключевые бизнес-выводы 
- Категория **Фото** является основным источником выручки.
- Топ-5 клиентов обеспечивают значительную долю дохода, что указывает на необходимость внедрения персональной программы лояльности.
- Наблюдается падение среднего чека к концу периода, что требует дополнительного исследования причин.
